Optima Browser

Справжній Windows-браузер · рідке скло · один EXE · WebView2 (Edge) · без Electron
⬇ Завантажити .exe GitHub

🔒Optima Vault

Історія й закладки шифруються AES-256-GCM (PBKDF2, 100 000 ітерацій). Забув пароль — дані недоступні назавжди.

🔐Примусовий HTTPS

http:// автоматично піднімається до https:// — реальний TLS 1.3, увімкнено за замовчуванням.

🛡Блокування реклами

100+ доменів трекерів на рівні рушія + виняток для окремого сайту.

⚡Один рушій

WebView2 створюється ліниво, призупиняється на стартовій — менше RAM. Клік по RAM-пілу — примусовий GC.

🌍12 мов перекладу

Меню ⋮ → Перекласти сторінку: від української до китайської. Вибір запам'ятовується.

🎬Вкладки по-своєму

Drag-reorder вкладок, Ctrl+Shift+T відновити закриту, приватні вкладки, імпорт/експорт закладок HTML.

🎨6 тем + ніч

Glass, Океан, Полум'я, Ліс, Сакура, Північ + авто-нічна тема 21:00–05:59.

🏆33 досягнення

Конімі-дощ, «слава україні», котячий дощ, TLS-апгрейд… Тости й прогрес у JSON.
